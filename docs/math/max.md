# max

### 概要

引数で渡された2つの整数のうち、大きい方の数値を返す。

### 仕様

|項目|内容|Emojicode|
|---|---|---|
|引数 1|整数型|🔢|
|引数 2|整数型|🔢|
|戻り値|整数型|🔢|

### Pythonでの実装例

```python
max(a, b)
```

### 注意点

`value = max(value, current_value)` のような変更ができません。
（原因不明）

この場合は一度他の変数に `max(value, current_value)` を代入し、その後 `value` にこれを代入しなおすなどの操作が必要になります。
