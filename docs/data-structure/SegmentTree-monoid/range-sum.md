# range-sum

### 概要

セグメントツリーでの、区間和のモノイド

### 仕様 `🍎`

|項目|内容|Emojicode|
|---|---|---|
|メンバ|モノイドの型|🔢|

#### メソッド

|メソッド|内容|引数|引数の内容|返り値|返り値の内容|
|---|---|---|---|---|---|
|🐸|値を取り出す|なし|なし|🔢|値|
|☀️|モノイド演算|🍎|共に演算するモノイド|🍎|演算後の値|

### Pythonでの実装例

```python
class Data:
    def __init__(self, x):
        self.x = x

    def __add__(self, other):
        return Data(self.x + other.x)
```

### 使い方

セグメントツリーの前に宣言してください。

### 注意点

セグメントツリーでの単位元が以下のようになっていることを確認してください。

```txt
🖍️🆕 val 🍎 ⬅️ 🆕🍎 0❗️
```
