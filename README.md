Emojicode 1.0 beta 2 の競技プログラミングライブラリです。
1.0 beta 2 以前には対応していません。

本ライブラリは Emojicode の競プロにおける実用化向上を目指しています。 🐇🐇🐇

まともなC++ライブラリは [Un_titled_Library](https://github.com/Rieul0406/Un_titled_Library) を参照してください。

Closure は全て main ブロックの中に記述しています。

実装等の詳細は [docs](docs) を参照してください。
docsの目次は [docs/toc](docs/toc.md) を参照してください。

以下はライブラリに直接アクセスできます。

- [io](io)
    - [tolist](io/tolist.emojic)
- [math](math)
    - [max](math/max.emojic)
    - [min](math/min.emojic)
